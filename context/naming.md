# Naming

## The project is called lasteverLM

**Id:** 38620fb4-6276-4e7c-8276-815cdd260e90
**Type:** decision
**Status:** active
**Evidence:** confirmed
**Source:** planning conversation, 2026-10-12

The product, the GitHub repositories (`lasteverLM`, `lasteverLM-<service>`)
and the Python packages (`lasteverlm-<service>`, lowercase as PyPI
normalizes) all carry the name lasteverLM, written with the capital LM
the way NotebookLM is.

**Reason:** the maintainer wanted a brand name rather than a description,
and "last ever LM" reads on its own as "the last LM you will need". The
LM suffix also says honestly what the project is modelled on. The name
was free everywhere it was checked (GitHub user and repositories, PyPI).

**Rejected alternatives:** descriptive names that say what the app does
(askyourfiles, explainmyfiles, filedistiller, docdigest) — free and
instantly understood, rejected because the maintainer preferred a brand
over a description; "AI Digest" — the best description of the output,
rejected because the name is taken by thousands of repositories and an
established website; "Source Analyzer" / "Source Walker" — rejected
because "source" reads as source code to the developers who will see the
repository; anything containing "Transformer" — rejected because the word
means a model architecture to the audience and would need explaining
away. The tagline "Please explain this to me", which the maintainer liked
as a name candidate, is kept as the frontend tagline instead.
